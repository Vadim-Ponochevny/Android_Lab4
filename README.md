<h1>Notes App</h1>
Приложение для создания и управления заметками. С помощью него можно добавлять, редактировать и удалять заметки в удобном интерфейсе.  

<h2>Что можно делать?</h2>
<ul>
  <li>Добавление новых заметок</li>
  <li>Редактирование существующих</li>
  <li>Удаление заметок</li>
  <li>Список всех заметок</li>
  <li>Поддержка поворота экрана без потери состояния</li>
</ul>

<h2>Основные технологии</h2>
<ul>
  <li><b>Kotlin</b></li>
  <li><b>MVVM</b></li>
  <li><b>Coroutines + Flow</b></li>
  <li><b>Hilt (DI)</b></li>
  <li><b>Room</b></li>
</ul>
