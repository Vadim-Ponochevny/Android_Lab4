Простое Android-приложение для создания и управления заметками.  
Позволяет добавлять, редактировать и удалять заметки в удобном интерфейсе.  

Функциональность приложения:
- Добавление новых заметок
- Редактирование существующих
- Удаление заметок
- Список всех заметок
- Поддержка поворота экрана без потери состояния

Технологии:
- Kotlin
- MVVM
- Coroutines + Flow
- Hilt (DI)
- Room
